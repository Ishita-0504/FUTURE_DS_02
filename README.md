# Customer Retention & Churn Analysis

## Project Overview
This project analyzes customer churn in the telecommunications industry using Tableau. The objective is to identify customer groups associated with higher churn and develop data-driven recommendations to improve customer retention.

## Tools Used
- Tableau — data visualization and interactive dashboard
- Microsoft Excel — data inspection and preparation

## Dataset
The analysis uses the Telco Customer Churn dataset, containing 7,043 customer records and information about customer tenure, contract type, payment method, and churn status.

## Key Performance Indicators
- **Total Customers:** 7,043
- **Churned Customers:** 1,869
- **Churn Rate:** 26.54%
- **Retention Rate:** 73.46%

## Key Findings
1. Month-to-month customers have the highest churn rate, at approximately 42.7%.
2. Customers on one-year contracts have a churn rate of approximately 11.2%.
3. Customers on two-year contracts have a churn rate of approximately 2.8%.
4. Electronic-check users account for a comparatively high number of churned customers.
5. Churn patterns differ across customer-tenure groups.

## Business Recommendations
- Encourage suitable month-to-month customers to consider longer-term contracts through loyalty benefits.
- Improve onboarding and engagement during the early stages of the customer relationship.
- Investigate the payment experience of electronic-check users.
- Monitor churn and retention KPIs regularly to evaluate improvement initiatives.

## Project Deliverables
- Tableau customer retention and churn dashboard
- Customer retention and churn analysis report
- Tableau workbook, where available

## Conclusion
The analysis highlights important patterns associated with customer churn, particularly contract type. The dashboard provides an accessible way to explore customer behavior and supports the development of targeted retention strategies.
